# AGI With AI — Freelancing Agency Website

A modern, high-converting landing page for **AGI With AI** — a startup-focused freelancing agency.

Built with **Next.js 16 (App Router)** + **TypeScript** + **Vanilla CSS** using a neo-brutalism design system.

## Tech Stack

- **Framework**: Next.js 16 (App Router, Turbopack)
- **Language**: TypeScript
- **Styling**: Vanilla CSS (custom design system, no Tailwind)
- **Icons**: Lucide React
- **Fonts**: Inter (Google Fonts)

## Sections

- **Hero** — Headline, subheadline, dual CTAs
- **Services** — 5 service cards (web dev, SaaS, AI, UI/UX, e-commerce)
- **Why Choose Us** — Key differentiators
- **Process** — 5-step visual timeline
- **Projects** — 0GSKILLS, KaggleIngest, A2ZBTC
- **Contact** — Form (opens mailto) + WhatsApp button
- **Footer** — Links, social placeholders

## Getting Started

```bash
cd agiwithai-freelance
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Design System

Based on `brandkit.md`:
- **Primary**: `#111111` (black)
- **Background**: `#FAFAFA` (soft white)
- **Accent**: `#FFF4CC` (warm yellow)
- **Neo-brutalism**: 2px solid black borders, offset hover shadow
